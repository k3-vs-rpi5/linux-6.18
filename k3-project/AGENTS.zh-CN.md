# linux-6.18 项目要求

本文件是内核项目的项目级契约，用于收紧（绝不放宽）工作区根 `AGENTS.md` 与
governance 文档中的协作契约，只记录本项目特有的内容。

- 范围是 K3 的内核侧工作：当前是配置增量，之后是对固定 BSP 源码树的声明式补丁，
  一律以 Debian 包交付。
- 固定源码是 `src/linux-6.18`，提交号记录在 `sources.lock.yaml`。该树绝不原地修改：
  源码变更以补丁文件加清单登记项的形式存在，使构建仅凭锁即可复现。
- 配置由基线与增量组成。基线是 `config/base.config`，取自板卡正在运行的内核并以摘要
  固定；每个更新在 `config/updateN.config` 声明一份增量，已解析的配置随每次构建封存。
- 只有定版更新才带版本号：打算保留的更新为 `6.18.3-generic-updateN`，迭代构建为
  `6.18.3-generic-dev+<commit>`。被记录的运行必须写明它用的是哪个版本。
- 在板卡上安装内核属于远端变更：只在操作者要求时执行，门先打印包身份，执行后报告实际
  运行的内核。
- 每次构建都在 Git 之外封存清单：基线配置摘要、增量、已解析配置摘要、交叉编译器身份、
  包名与包摘要。
- 内核构建在主机侧进行，使用工作区工具链
  `spacemit-toolchain-linux-glibc-x86_64-v1.2.4`；绝不读取设备凭据记录，那些记录只属于
  操作者。
